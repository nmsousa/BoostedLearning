# Boostionary --- French Core Vocabulary & Thematic Progression

## Curriculum specification and implementation brief for Kiro

**Purpose:** Define a pedagogically coherent French curriculum in which
learners first unlock high-utility language building blocks in **Core
Vocabulary**, then use them in themed branches, then return to
progressively more advanced Core levels. This document is a curriculum
and product specification, not merely a word list.

**Target language:** Standard contemporary French as used in France,
with broadly understandable international French.\
**Learner interface language:** English.\
**Primary progression:** Pre-A1/A1 → A2 → B1 → B2.\
**Product metaphor:** The central Core Vocabulary node is the
grammatical and lexical engine; thematic branches are places where
learners apply that engine to real-life topics.

------------------------------------------------------------------------

# 1. Product vision and non-negotiable learning principle

The learner should experience this loop:

1.  Learn a small, carefully selected set of **Core** words and
    structures.
2.  Unlock thematic branches and choose topics freely.
3.  Build meaningful sentences using the newly learned theme vocabulary
    and the Core language already mastered.
4.  Complete a minimum number of thematic milestones.
5.  Unlock the next Core level, which adds new ways to express meaning.
6.  Revisit themes at the new level and produce richer, more precise
    sentences.

**Core is not a general vocabulary topic.** It is the reusable language
toolkit: pronouns, articles, determiners, high-frequency verbs, question
words, negation, prepositions, connectors, sentence patterns and later
grammar structures.

**Themes are not grammar courses.** They supply the topic-specific
nouns, verbs, adjectives, collocations and expressions needed to talk
about a subject: health, travel, education, food, work, home,
relationships, culture, nature, science and technology, etc.

The two systems must work together. A learner who has completed Core L1
and a Food L1 lesson should be able to produce simple French sentences
about food, not just recognise a list of food nouns.

## Critical design rule

Do not implement "Core L1 = first three skills in the existing course
deck" unless a human-reviewed curriculum audit proves that those skills
form a coherent foundational set. Course order is not a reliable proxy
for linguistic dependency.

Build a **new, explicit curriculum map** that references existing
skill/card IDs where appropriate. Do not blindly reorder, duplicate or
discard the current course content.

# 2. Evidence and curriculum methodology

Use three complementary lenses. No single source should dictate the
entire curriculum.

## 2.1 Frequency: teach useful words early

Routledge's *A Frequency Dictionary of French* (second edition, 2026)
describes 5,000 frequent French word families using a 300-million-word
corpus, with spoken and written material, examples, translations and
register information. This supports prioritising high-frequency lemmas,
but raw frequency alone is not enough: a frequent function word may be
difficult to teach in isolation, while a less frequent word may be
essential for a learner's immediate goal.

Reference: -
https://www.routledge.com/A-Frequency-Dictionary-of-French-Core-Vocabulary-for-Learners/Law-LeBras/p/book/9781032741178

UCLouvain's FLELex is a CEFR-graded lexical resource for French as a
foreign language. It reports word frequencies across CEFR levels based
on learner textbooks and simplified readers. It is a particularly
relevant source for assigning approximate learning levels: -
https://cental.uclouvain.be/cefrlex/flelex/ - Project overview:
https://cental.uclouvain.be/cefrlex/

Other frequency lists can be used as cross-checks, not as unquestionable
truth: -
https://www.adsonant.com/resources/french/1000-most-common-words/ -
https://zipf.app/learn/fr/

## 2.2 CEFR: teach what learners can do

Use CEFR as a **communicative progression framework**, not as a rigid
official vocabulary inventory.

Broad progression: - **A1:** familiar expressions, personal details,
concrete needs, very simple one-clause sentences, basic questions and
answers. - **A2:** routine exchanges and simple descriptions about
familiar areas such as family, shopping, work and immediate
surroundings. - **B1:** connected discourse on familiar topics;
experiences, plans, hopes, reasons and explanations. - **B2:** clearer,
more detailed argumentation; advantages/disadvantages, abstract
subjects, nuance and more flexible language.

References: - Council of Europe CEFR descriptor search:
https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors -
French public-service explanation of CEFR levels:
https://www.service-public.gouv.fr/particuliers/vosdroits/F34739?lang=en

## 2.3 French-specific grammar: sentence-building dependencies

Use English-language French teaching references to validate the order
and treatment of French grammar: - Lawless French A1 grammar:
https://www.lawlessfrench.com/verb-conjugations/a1-grammar - Lawless
French grammar index: https://www.lawlessfrench.com/grammar/ - Kwiziq
French grammar revision map: https://french.kwiziq.com/revision/grammar

These references highlight the importance of articles, gender/number
agreement, subject pronouns, present-tense conjugation, questions,
negation, prepositions, partitive articles, possessives, demonstratives
and common fixed constructions.

**Important:** English-to-French translation is not one-to-one. French
has grammatical gender, obligatory subject pronouns in ordinary finite
clauses, verb agreement, contracted articles (au, aux, du, des),
partitive articles and different preposition patterns. Teach French
patterns, not English word substitution.

# 3. Recommended overall progression

Use **six Core tiers** for a first complete A1--B2 progression. The
exact number of words and skills can be tuned after inspecting the
existing deck, but the learning outcomes should remain stable.

  -----------------------------------------------------------------------

                                                        can begin to do
  ----------------- ----------------- ----------------- -----------------

                                      clause            identify things,
                                                        state simple
                                                        facts, express
                                                        basic needs and
                                                        likes

  Core 2            A1 → A2           Expand a simple   Ask questions,
                                      clause            negate, describe,
                                                        locate, quantify,
                                                        talk about
                                                        routines and
                                                        immediate plans

  Core 3            A2                Talk across time  Describe
                                                        routines,
                                                        recent/past
                                                        events and
                                                        near-future

                                                        simple ideas

  Core 4            A2 → B1           Make sentences    Refer to
                                      more flexible     objects/people,
                                                        compare, explain
                                                        reasons, express
                                                        obligation,
                                                        possibility and
                                                        preferences

  Core 5            B1                Build connected   Narrate, explain,
                                      discourse         hypothesise,
                                                        express opinions,
                                                        contrast and
                                                        justify

                                      nuance            structure
                                                        arguments,
                                                        discuss abstract
                                                        topics and use
                                                        varied registers
  -----------------------------------------------------------------------

Do not make every tier a huge vocabulary dump. Core tiers should
introduce a manageable number of **high-leverage items and structures**,
with repeated practice and cumulative reuse.

Suggested starting scale (adjust after measuring the actual lesson
engine): - Core L1: 45--65 lexical items/constructions, with very high
reuse. - Core L2: 55--75 new items/constructions. - Core L3: 60--80. -
Core L4: 60--80. - Core L5: 70--90. - Core L6: 70--90.

These are planning ranges, not scientifically fixed vocabulary
thresholds. A "lexical item" may be a word, a grammatical form, or a
useful multi-word construction. Do not count every conjugated form as a
separate vocabulary word.

# 4. Core Vocabulary curriculum in detail

## Core Level 1 --- The basic sentence engine (Pre-A1/A1)

**Outcome:** The learner can produce and understand short, simple
statements about people, objects, identity, location, possession, likes
and immediate needs.

### 4.1.1 Subject pronouns

Teach as a French system, with sound and usage notes:

  -----------------------------------------------------------------------
  French                  English guide           Notes
  ----------------------- ----------------------- -----------------------
  je / j'                 I                       j' before a vowel or
                                                  mute h

  tu                      you (singular informal) Familiar/informal

  il                      he / it                 Masculine singular

  elle                    she / it                Feminine singular

  on                      one / people / we       Very common spoken
                                                  "we"; introduce early

  nous                    we                      Standard "we"; useful
                                                  for recognition and
                                                  production

  vous                    you (plural or polite   Essential politeness
                          singular)               distinction

  ils                     they                    Masculine or mixed
                                                  group

  elles                   they                    All-feminine group
  -----------------------------------------------------------------------

Do not teach English "it" as a direct, universal French pronoun
equivalent. French nouns have grammatical gender, and the subject
pronoun agrees with the noun's grammatical gender.

### 4.1.2 Articles and noun framing

Teach together with gender and number: - Definite: **le, la, l', les**
--- the - Indefinite: **un, une, des** --- a/an, some - Gender labels:
**masculin, féminin** - Number: singular/plural - Elision: **l'ami,
l'école** - Basic noun + article chunks: **un livre, une maison, le
travail, les amis**

Core rule: every new French noun card should normally show its article
and gender, e.g. **la maison (f.)**, not just *maison*.

Introduce the fact that French often uses a definite article where
English does not, but do not overload the first lesson with all
exceptions.

### 4.1.3 Foundational verbs

Teach the infinitive, meaning, high-value present forms and sentence
frames.

  -----------------------------------------------------------------------
  Infinitive              English                 Essential early
                                                  patterns
  ----------------------- ----------------------- -----------------------
  être                    to be                   je suis, tu es, il/elle
                                                  est, nous sommes, vous
                                                  êtes, ils/elles sont

  avoir                   to have                 j'ai, tu as, il/elle a,
                                                  nous avons, vous avez,
                                                  ils/elles ont

  s'appeler               to be called            je m'appelle...,
                                                  comment tu t'appelles ?

  habiter                 to live/reside          j'habite à...

  aimer                   to like/love            j'aime..., je n'aime
                                                  pas... (negative
                                                  pattern can be
                                                  previewed)

  parler                  to speak                je parle
                                                  français/anglais

  aller                   to go                   je vais à...

  faire                   to do/make              je fais...; il fait...
                                                  (common expressions)

  vouloir                 to want                 je veux... (common
                                                  immediate need)

  pouvoir                 can/to be able          je peux... (basic
                                                  requests/ability)
  -----------------------------------------------------------------------

Prioritise **être, avoir, aller, faire** as irregular high-utility
verbs. Introduce **vouloir** and **pouvoir** through practical chunks
rather than requiring mastery of every use immediately.

### 4.1.4 Essential determiners and pointing words

-   **mon, ma, mes** --- my
-   **ton, ta, tes** --- your (informal)
-   **son, sa, ses** --- his/her/its (agreement with the noun)
-   **ce, cet, cette, ces** --- this/that/these/those (determiners;
    teach gradually)
-   **un, une, des** --- indefinite articles (also covered above)

Avoid teaching possessives as if French chooses *son/sa* according to
the owner's gender. French possessive adjective agrees with the
possessed noun: **son livre**, **sa maison**.

### 4.1.5 Essential sentence glue

-   **et** --- and
-   **ou** --- or
-   **mais** --- but
-   **avec** --- with
-   **sans** --- without
-   **à** --- to/at/in (context-dependent)
-   **de / d'** --- of/from (context-dependent)
-   **dans** --- in/inside
-   **sur** --- on
-   **ici** --- here
-   **là** --- there
-   **oui** --- yes
-   **non** --- no
-   **ne...pas** --- not (introduce as a paired construction, not two
    unrelated words)

Do not pretend each preposition has a single English translation. Teach
it in short examples and collocations.

### 4.1.6 Essential question language

-   **qui** --- who
-   **quoi / qu'est-ce que** --- what
-   **où** --- where
-   **quand** --- when
-   **comment** --- how
-   **pourquoi** --- why
-   **combien** --- how much/how many
-   **quel / quelle / quels / quelles** --- which/what (agreement)
-   **est-ce que** --- question-forming structure
-   Intonation questions: **Tu habites ici ?**
-   Basic question pattern: **Où est... ?**, **Qu'est-ce que c'est ?**

### 4.1.7 Core adjectives and adverbs

Adjectives: - bon / bonne --- good - mauvais / mauvaise --- bad - grand
/ grande --- big/tall - petit / petite --- small - nouveau / nouvelle
--- new - vieux / vieille --- old - beau / belle --- beautiful - facile
--- easy - difficile --- difficult - content / contente --- happy/glad -
fatigué / fatiguée --- tired - français / française --- French

Adverbs and useful expressions: - **très** --- very - **bien** ---
well - **mal** --- badly - **aussi** --- also/too - **beaucoup** --- a
lot - **un peu** --- a little - **maintenant** --- now - **aujourd'hui**
--- today - **toujours** --- always/still (context-dependent) -
**souvent** --- often

Teach adjective agreement and common placement through examples, not as
a giant exception list.

### 4.1.8 Core L1 sentence patterns

The lesson engine should practise these patterns explicitly:

1.  **Subject + être + noun/adjective**\
    *Je suis étudiant.* / *Elle est contente.*
2.  **Subject + avoir + noun**\
    *J'ai un frère.* / *Nous avons une maison.*
3.  **Subject + verb + object**\
    *Je parle français.* / *Tu aimes le café.*
4.  **C'est + noun/adjective**\
    *C'est une bonne idée.*
5.  **Il y a + noun**\
    *Il y a un problème.*
6.  **Subject + verb + place**\
    *J'habite à Bruxelles.*
7.  **Subject + ne...pas + verb**\
    *Je ne parle pas allemand.*
8.  **Question + short answer**\
    *Tu habites où ? --- J'habite à Bruxelles.*
9.  **Possessive + noun**\
    *C'est mon livre.*
10. **Noun + adjective**\
    *Une petite maison.*

**Core L1 exit test:** Given familiar words, learner can create simple
affirmative, negative and interrogative sentences, introduce themselves,
describe a person/object, express possession and state likes/basic
needs. They should not need past-tense narration or complex subordinate
clauses yet.

## Core Level 2 --- Expand, describe, ask and locate (A1 → A2)

**Outcome:** The learner can add detail to basic sentences and handle
common everyday exchanges.

### New grammar and structures

-   Present tense of regular **-er** verbs; selected high-frequency
    **-ir/-re** verbs.
-   More complete present forms of **aller, faire, vouloir, pouvoir,
    devoir, prendre, venir**.
-   Negation: **ne...pas**, **ne...jamais**, **ne...plus** (recognition
    and productive use in common contexts).
-   Questions: intonation, **est-ce que**, question words, basic
    inversion recognition.
-   Partitive articles: **du, de la, de l', des**.
-   Contracted articles: **à + le = au; à + les = aux; de + le = du;
    de + les = des**.
-   Place prepositions: **devant, derrière, sous, entre, près de, loin
    de, à côté de, en face de**.
-   Possessives: **notre/nos, votre/vos, leur/leurs**.
-   Demonstratives: **ce/cet/cette/ces**.
-   Quantifiers: **un peu de, beaucoup de, assez de, trop de, pas de**.
-   Frequency: **souvent, parfois, rarement, normalement, d'habitude**.
-   Time: **hier, demain, tôt, tard, bientôt, ensuite, puis**.
-   Adjective agreement and common position; colours; comparison
    preview.
-   **il y a**, **c'est / il est**, **on** in common spoken uses.
-   Basic imperative chunks: **regardez, écoute, prenez, allez-y**
    (teach according to communicative need).

### Core L2 vocabulary set

-   Verbs: **prendre, venir, partir, sortir, entrer, arriver, rester,
    attendre, chercher, trouver, acheter, payer, manger, boire, choisir,
    finir, dormir, lire, écrire, écouter, regarder, travailler, étudier,
    comprendre, connaître, savoir, devoir, préférer, essayer,
    utiliser**.
-   Connectors: **parce que, donc, alors, puis, ensuite, quand, si**
    (simple conditional meaning "if").
-   Adverbs: **déjà, encore, enfin, seulement, vraiment, peut-être,
    probablement, ensemble, rapidement, lentement**.
-   Quantities: **tout, tous, toute, toutes; chaque; plusieurs;
    quelques; assez; trop; plus; moins**.
-   Practical expressions: **j'ai besoin de**, **j'ai envie de**, **je
    voudrais**, **je peux... ?**, **il faut**, **ça va**, **je ne sais
    pas**.

### Core L2 sentence patterns

-   **Je voudrais + noun/infinitive** --- *Je voudrais un café.*
-   **Je peux / je dois / je veux + infinitive** --- *Je dois partir.*
-   **Il faut + infinitive** --- *Il faut réserver.*
-   **Subject + ne...jamais/plus + verb** --- *Je ne mange jamais ici.*
-   **Verb + object + place/time** --- *J'achète du pain à la
    boulangerie.*
-   **Comparison** --- *C'est plus grand que...*
-   **Reason/result** --- *Je reste à la maison parce qu'il pleut.*
-   **Routine/frequency** --- *Je prends souvent le bus.*
-   **Question with quantity** --- *Combien ça coûte ?*

------------------------------------------------------------------------

## Core Level 3 --- Time, experience and plans (A2)

**Outcome:** The learner can talk about habitual actions, completed past
events, recent events and near-future plans.

### New grammar and structures

-   **Passé composé** with **avoir**; common verbs with **être**; basic
    agreement awareness.
-   **Futur proche:** aller + infinitive.
-   **Passé récent:** venir de + infinitive.
-   Reflexive verbs in present and common past contexts: **se lever, se
    réveiller, se coucher, s'habiller, se sentir**.
-   Direct object pronouns: **me, te, le, la, nous, vous, les** in
    simple placement.
-   Indirect object pronouns: **lui, leur** in high-frequency patterns
    (introduce carefully).
-   Conjunctions: **mais, parce que, quand, si, pendant que**.
-   Time markers: **avant, après, pendant, depuis, il y a** (contrast
    meaning in context).
-   Basic relative **qui / que** in short sentences.
-   Common imperative forms for instructions and advice.

### Core L3 vocabulary set

-   Verbs: **passer, raconter, rencontrer, oublier, se souvenir,
    recevoir, envoyer, répondre, décider, commencer, continuer,
    terminer, réussir, manquer, voyager, revenir, monter, descendre,
    ouvrir, fermer, conduire, apprendre, enseigner**.
-   Time and sequence: **la veille, le lendemain, la semaine dernière,
    le mois prochain, d'abord, après, pendant, finalement, tout à
    coup**.
-   Experience words: **expérience, souvenir, voyage, événement, fois,
    moment, habitude, projet, invitation**.
-   Connectors: **puis, ensuite, enfin, pourtant** (simple contrast).
-   Frequency and duration: **depuis, pendant, souvent, rarement,
    longtemps, récemment**.

### Core L3 sentence patterns

-   *Hier, j'ai travaillé toute la journée.*
-   *Nous sommes allés au restaurant.*
-   *Je vais visiter Paris demain.*
-   *Je viens de terminer.*
-   *Je me lève à sept heures.*
-   *Je lui ai téléphoné.*
-   *Quand je suis arrivé, il pleuvait.* (the imperfect contrast can be
    a later preview; do not require full mastery at this tier)
-   *D'abord..., ensuite..., finalement...*

------------------------------------------------------------------------

## Core Level 4 --- Flexible sentences and relationships between ideas (A2 → B1)

**Outcome:** The learner can describe more precisely, avoid repetition,
compare alternatives and explain practical decisions.

### New grammar and structures

-   **Imparfait** for habits/background and contrast with passé composé.
-   Future simple: common forms and practical plans/predictions.
-   Conditional present for politeness and hypothetical requests: **je
    voudrais, pourriez-vous, ce serait**.
-   Direct/indirect object pronouns in more contexts; pronoun order.
-   **Y** and **en** in common constructions.
-   Relative pronouns **qui, que, où**.
-   Comparatives and superlatives: **plus...que, moins...que,
    aussi...que, le plus**.
-   Cause, consequence, opposition: **car, puisque, alors, donc,
    pourtant, cependant, par contre**.
-   Infinitive constructions: **avant de, après avoir**
    (recognition/selected production), **pour + infinitive**.
-   Obligation/possibility: **il faut, devoir, pouvoir, avoir le droit
    de, être obligé de**.
-   Pronoun **on** and register-appropriate alternatives.

### Core L4 vocabulary set

-   Verbs: **améliorer, changer, remplacer, éviter, permettre, empêcher,
    proposer, expliquer, conseiller, choisir, comparer, partager,
    participer, dépendre, appartenir, sembler, paraître, devenir,
    suivre, soutenir**.
-   Abstract nouns: **raison, choix, avantage, inconvénient, différence,
    conséquence, résultat, besoin, possibilité, décision, comportement,
    relation, qualité**.
-   Connectors: **cependant, pourtant, tandis que, alors que, puisque,
    grâce à, à cause de, malgré**.
-   Adverbs: **plutôt, surtout, particulièrement, probablement,
    certainement, normalement, récemment**.

### Core L4 sentence patterns

-   *Quand j'étais enfant, je jouais souvent dehors.*
-   *J'ai choisi ce cours parce qu'il est plus pratique.*
-   *C'est le meilleur choix pour moi.*
-   *Je vais en parler avec elle.*
-   *J'en ai besoin.*
-   *Le quartier où j'habite est calme.*
-   *Même si c'est cher, ça vaut la peine.*
-   *Pour réussir, il faut pratiquer régulièrement.*

------------------------------------------------------------------------

## Core Level 5 --- Connected discourse, opinions and explanations (B1)

**Outcome:** The learner can narrate and explain, give opinions, support
claims and discuss familiar abstract issues.

### New grammar and structures

-   Confident use of passé composé vs imparfait.
-   Pluperfect (plus-que-parfait) in common narratives.
-   Conditional present and past in practical contexts.
-   Subjunctive present in common trigger expressions: **il faut que,
    bien que, pour que, je veux que** (teach high-frequency patterns,
    not a giant conjugation table).
-   Relative clauses with **dont** and **lequel** in common uses.
-   More flexible pronoun combinations.
-   Reported speech basics and **dire que / penser que / croire que**.
-   Hypothesis with **si + présent/futur**, **si +
    imparfait/conditionnel**.
-   Concession and contrast: **même si, bien que, malgré, en revanche**.
-   Discourse sequencing and paragraph organisation.

### Core L5 vocabulary set

-   Opinion: **à mon avis, selon moi, je trouve que, je pense que, je
    suis d'accord, je ne suis pas d'accord**.
-   Reasoning: **en effet, en fait, d'ailleurs, pourtant, néanmoins, par
    conséquent, en revanche, notamment**.
-   Verbs: **considérer, croire, supposer, reconnaître, remarquer,
    constater, convaincre, défendre, critiquer, résoudre, développer,
    atteindre, réussir, échouer, contribuer**.
-   Abstract nouns: **opinion, point de vue, société, environnement,
    économie, égalité, liberté, responsabilité, confiance, difficulté,
    objectif, développement**.
-   Qualification: **certain, probable, éventuel, principal, essentiel,
    nécessaire, suffisant, similaire, différent**.

### Core L5 sentence patterns

-   *À mon avis, cette solution est plus efficace.*
-   *Je pense que nous devrions changer de méthode.*
-   *Même si je comprends ton point de vue, je ne suis pas entièrement
    d'accord.*
-   *Si j'avais plus de temps, je voyagerais davantage.*
-   *Il faut que nous trouvions une solution.*
-   *Le projet auquel je participe est intéressant.*
-   *Quand je suis arrivé, la réunion avait déjà commencé.*

------------------------------------------------------------------------

## Core Level 6 --- Precision, nuance and argumentation (B1 → B2)

**Outcome:** The learner can discuss less concrete topics, qualify
arguments, express uncertainty and write/speak in a more structured way.

### New grammar and structures

-   More confident subjunctive use and common subjunctive conjunctions.
-   Conditional past and complex hypotheses.
-   Passive voice and impersonal constructions.
-   Gérondif and participial structures in common written/spoken
    contexts.
-   Advanced relative pronouns and complex sentence linking.
-   Reported speech and tense concordance in common contexts.
-   Nuanced connectors: **or, toutefois, en outre, autrement dit,
    certes, tandis que, faute de, à condition que**.
-   Register: familiar, neutral and formal alternatives.
-   Lexical precision, collocations, idiomatic chunks and avoiding
    repetition.

### Core L6 vocabulary set

-   Argumentation: **enjeu, démarche, approche, perspective, hypothèse,
    constat, implication, limite, mesure, évolution, tendance,
    dispositif**.
-   Verbs: **remettre en question, souligner, démontrer, établir,
    envisager, favoriser, réduire, accroître, remettre, relever,
    s'avérer, représenter, constituer, aboutir à**.
-   Connectors: **en outre, toutefois, néanmoins, autrement dit, en
    d'autres termes, dans la mesure où, à condition que, faute de, au
    contraire**.
-   Precision: **éventuellement, apparemment, vraisemblablement,
    relativement, considérablement, progressivement, auparavant**.

Do not make rare formal words a prerequisite for ordinary communication.
These belong in later enrichment and should be taught with register
labels and authentic contexts.

# 5. Thematic branches: what they contain and how their levels work

The themes in the visual map (Travel, Daily Life, Food & Drink, Home,
Relationships, Health, Culture, Education, Nature, Science & Technology,
Business) are a good starting taxonomy.

A thematic branch contains **the vocabulary and communicative tasks for
that domain**. It is not a flat list of words. Each theme has tiered
lesson packs, and the learner's available Core level determines the
sentence complexity that can be practised.

## 5.1 What does "Theme Level 1" mean?

It must **not** simply mean "the first skill in the existing theme" or
"the first node type across every skill".

Define each theme tier as a curated **communicative milestone**: - Theme
L1: identify, name, request and make simple statements in the topic
using Core L1. - Theme L2: describe, ask questions, quantify and explain
simple preferences using Core L2. - Theme L3: discuss past experiences

## 5.3 Theme vocabulary is levelled independently from Core grammar

A theme may contain an advanced noun before the learner can use it in a
complex sentence. That is acceptable if it is clearly marked as
recognition-only or introduced with a simple sentence frame.

Conversely, basic words such as **le médecin**, **l'école**, **le
billet** or **le téléphone** should not be artificially delayed just
because the theme's later branch is B1.

Each vocabulary item should have: - a recommended first-introduction
level; - a theme/domain tag (one or more); - a CEFR estimate; - whether
it is active (must produce) or receptive (recognise); - a set of
validated collocations/patterns; - grammar requirements for productive
use.

# 6. Unlock rules --- recommended product behaviour

Use the following default rules unless the existing product has a
technical limitation.

## 6.1 Alternating Core and theme tiers

1.  **Core L1** is the first mandatory node.
2.  Completing Core L1 unlocks **Theme L1** for all available themes.
3.  Learner can choose any themes in any order.
4.  Completing **3 distinct Theme L1 milestones** unlocks Core L2.
5.  Completing Core L2 unlocks Theme L2 across the branches.
6.  Completing **3 distinct Theme L2 milestones** unlocks Core L3.
7.  Repeat the same loop through Core L6.

Recommended threshold: **X = 3 distinct themes per tier**.

Why three? It provides meaningful choice and application without forcing
the learner to complete every theme before advancing. Make X a course
configuration value, not a hard-coded assumption.

Do not count replaying the same theme milestone multiple times as
multiple themes. Count unique `(themeId, tier)` completions.

## 6.2 Completion definition

A theme milestone counts as complete only when the learner meets the
existing chapter/skill completion rule for all required activities in
that milestone. Reuse the app's established completion semantics where
possible.

Do not count: - opening a node; - previewing vocabulary; - partially
completing exercises; - replaying a previously completed node as a new
completion.

If the app currently has multiple activity types (flip, quiz, write,
match, builder, blanks), use the existing completion contract. Do not
silently change its meaning in this feature.

## 6.3 Core level completion

Core tier completion should require: - all required Core skills/lessons
complete; - a minimum mastery threshold if the existing engine supports
it; - a final cumulative sentence-building checkpoint.

Do not make a learner pass a high-stakes exam. Allow practice and retry.

## 6.4 Late entry, skipped topics and future content

-   All themes should be available at the current unlocked tier.
-   A learner may ignore a theme indefinitely.
-   Completing Theme L1 in Health does not automatically complete Health
    L2.
-   When Core L3 unlocks, previously completed themes stay completed at
    their earlier tier; their next tier becomes available.
-   If a theme has no content at a given tier, do not count it among the
    available choices or as a completion requirement.
-   If fewer than three themes exist for a tier, lower the threshold
    safely or use a configured threshold based on available themes.
-   Recalculate unlocks from completion records so state can be
    recovered after app reinstall/sync.
-   Never lock a learner out of already completed content.

# 7. The essential feature: combine Core words with theme words

This is pedagogically central, not a cosmetic enhancement.

**Recommendation: implement the full vocabulary-mixing model as part of
the feature**, but do it in a controlled, backward-compatible way. If a
complete session-engine refactor is too risky for the first delivery,
implement a minimal shared vocabulary-set layer first, then migrate
activity types incrementally. Do not ship a progression system that
claims Core words are reused if exercises still draw only from a theme's
local cards.

## 7.1 Vocabulary sources for a session

Each exercise/session should be built from: 1. **Current Core tier
vocabulary** --- the Core items available at the learner's current Core
level. 2. **Previously mastered Core vocabulary** --- cumulative items
from earlier Core tiers. 3. **Current theme vocabulary** --- the items
introduced in the selected theme milestone. 4. **Previously mastered
theme vocabulary** --- selected items for spaced review, not necessarily
the entire historical theme deck. 5. **Bridge vocabulary** ---
high-utility words needed to make a natural sentence (articles,
auxiliaries, prepositions, pronouns, common verbs). These can be
included even if they are not the target of the exercise, but should not
be falsely marked as newly taught.

Do not add every mastered word to every exercise. Select a manageable
subset based on activity type, level, and learning objective.

## 7.2 Suggested weighting

Initial heuristic for sentence-building exercises: - 40% current theme
target vocabulary; - 30% current Core tier target structures/items; -
20% previously learned Core/theme review; - 10% bridge words needed for
grammaticality.

These are starting values for experimentation, not research-established
percentages. Make weights configurable and log performance to tune them.

For flashcard-only or matching activities, use the current lesson's
target items more heavily. For sentence builder and writing activities,
mix vocabulary more aggressively.

## 7.3 Prevent impossible sentence generation

Every generated exercise must satisfy: - all required grammar structures
have been taught or explicitly scaffolded; - all target lexical items
are known, introduced in the current lesson, or supported by a hint; -
the sentence is grammatical and idiomatic French; - noun gender/article
and adjective agreement are correct; - verb conjugation matches the
subject and tense; - preposition + article contractions are correct; -
translation is natural English, not mechanically word-for-word; - no
unsupported advanced grammar is required to solve a beginner task.

If a theme noun requires an article, include the correct article as part
of the lexical entry or as a bridge item.

# 9. French vocabulary data model --- required metadata

Do not store a French word as only `{ french, english }`. French needs
richer metadata to support correct sentence generation.

Suggested conceptual model (adapt names to the existing app
architecture):

``` ts
interface VocabularyItem {
  id: string;
  lemma: string;                 // e.g. "maison"
  displayForm: string;           // e.g. "la maison"
  english: string[];             // context-aware meanings
  partOfSpeech: PartOfSpeech;
  gender?: "masculine" | "feminine";
  number?: "singular" | "plural" | "invariant";
  infinitive?: string;           // for verb forms
  conjugationGroup?: "er" | "ir" | "re" | "irregular" | "reflexive";
  reflexive?: boolean;
  conjugations?: Record<string, string>;
  adjectiveForms?: {
    masculineSingular?: string;
    feminineSingular?: string;
    masculinePlural?: string;
    femininePlural?: string;
  };
  phonetics?: {
    ipa?: string;
    audioKey?: string;
  };
  cefrLevel: "PRE_A1" | "A1" | "A2" | "B1" | "B2" | "C1";
  coreTier?: 1 | 2 | 3 | 4 | 5 | 6;
  themeIds: string[];
  tags: string[];
  register?: "neutral" | "formal" | "informal" | "colloquial";
  isFunctionWord: boolean;
  isProductiveTarget: boolean;
  collocations?: string[];
  exampleSentenceIds?: string[];
  prerequisites?: string[];
  notesForEnglishSpeakers?: string[];
}
```

For multi-word expressions, use the same vocabulary abstraction or a
related `ExpressionItem`: - **avoir besoin de** --- to need - **avoir
envie de** --- to feel like/want - **avoir mal à** --- to have pain in -
**il y a** --- there is/are - **il faut** --- it is necessary / one
must - **être en train de** --- to be in the middle of - **venir de +
infinitive** --- to have just done something - **aller + infinitive**
--- near future - **prendre rendez-vous** --- to make an appointment -
**faire attention à** --- to pay attention to

For a verb, separate the lemma from conjugated forms. Do not create
separate unrelated vocabulary cards for *suis*, *es*, *est*, *sommes*,
etc. They should be forms of **être**, while still being individually
testable.

For nouns, store grammatical gender and article. For adjectives, store
agreement forms or a reliable inflection rule. For verbs, store
conjugation data and common constructions. For prepositions, store
example patterns because one English gloss is misleading.

# 10. Skill and activity design

Reuse the app's existing activity types (flip, quiz, write, match,
builder, blanks) where possible, but give each a clear pedagogical role.

## Core lesson activities

-   **Recognition:** match French items to English meaning; include
    audio where available.
-   **Form awareness:** select the correct article, gender, plural or
    conjugated verb.
-   **Controlled production:** complete a sentence with the correct
    pronoun, article, verb form or connector.
-   **Sentence builder:** assemble a grammatical sentence from shuffled
    chunks/words.
-   **Translation:** translate short, level-appropriate English prompts
    into natural French.
-   **Transformation:** affirmative ↔ negative; statement ↔ question;
    present ↔ past/future when taught.
-   **Cumulative retrieval:** mix current and previously learned Core
    items.

## Theme lesson activities

-   Introduce topic vocabulary in useful chunks and collocations.
-   Match topic words to pictures/definitions/translations.
-   Complete short dialogues in the theme.
-   Build sentences using the current Core structures.
-   Write or translate a short practical message.
-   Review selected older vocabulary through spaced repetition.

## Sentence builder requirements

A builder must not accept only one arbitrary token order if French
grammar permits multiple natural answers. Use validated target
sentence(s), accepted alternatives and a structured representation where
possible.

For French specifically: - Keep **ne ... pas** around the finite verb in
standard written French; if teaching spoken omission of *ne*, label it
as informal recognition, not the default beginner form. - Keep object
pronouns before the conjugated verb in ordinary simple tenses: **Je le
vois**. - Keep adjective agreement correct. - Respect elision: **j'aime,
l'école, d'accord**. - Respect contractions: **au, aux, du, des**. -
Treat multi-word chunks such as **il y a** as meaningful units where
appropriate. - Distinguish **c'est** from **il/elle est** through
contextual examples. - Do not translate *on* only as "one"; it
frequently means "we" in everyday French. - Distinguish **savoir** (know
a fact/how to) from **connaître** (be familiar with a
person/place/thing). - Distinguish **bon** from **bien** through
examples.

# 11. Quality, sequencing and content validation

## 11.1 Avoid these curriculum mistakes

1.  **No flat frequency dump.** The most frequent words include function
    words whose meaning is highly contextual. Teach them in patterns.
2.  **No English word-for-word mapping.** French article, gender and
    preposition use often differ from English.
3.  **No false CEFR precision.** CEFR word levels vary by corpus and
    curriculum. Store a recommended level and confidence/source, not a
    claim that a word is officially A1.
4.  **No one-skill-equals-one-tier assumption.** A thematic tier is a
    curated learning milestone.
5.  **No isolated conjugation overload.** Prioritise common person forms
    and useful sentence frames; expand systematically.
6.  **No advanced grammar in beginner sentence builder tasks** unless
    the advanced structure is provided as a fixed chunk and the task
    explicitly teaches it.
7.  **No theme isolation.** Core vocabulary must recur in theme
    exercises.
8.  **No duplicate lexical entries** for the same lemma unless meaning,
    register or grammatical use genuinely differs.
9.  **No missing gender/article.** French noun cards should normally
    expose these.
10. **No incorrect or unnatural translations.** English should
    communicate the intended meaning, not mimic French syntax.

## 11.2 Validation metadata

For each vocabulary item and example sentence, track: - source/reference
or editorial provenance; - CEFR estimate and confidence; -
native-speaker review status; - spelling/diacritics validation; -
gender/agreement validation; - pronunciation/audio status; - register
and regional variation; - example translation review; - grammar
prerequisites.

## 11.3 Recommended content review process

1.  Generate candidate words from frequency and CEFR resources.
2.  Filter for communicative usefulness and theme relevance.
3.  Assign an initial CEFR estimate.
4.  Check prerequisite grammar and sentence patterns.
5.  Draft examples.
6.  Have a French-proficient reviewer validate naturalness, register and
    translations.
7.  Test every example through the actual sentence-builder constraints.
8.  Pilot with learners and revise based on error rates and completion
    data.

Do not attempt a risky all-at-once rewrite. Preserve existing

activities, IDs, CEFR levels, themes and duplicates. - Identify which

Produce a mapping report: existing item → proposed Core tier/theme tier
→ action (reuse/update/create/defer). - Do not assume the current course
deck has the same IDs, structure or content as any other language.

**Deliverable:** an audit and mapping proposal before destructive
changes.

## Phase 2 --- Implement curriculum metadata and unlock logic

-   Add explicit Core tiers and theme tiers using stable IDs.
-   Make tier prerequisites and the "three distinct themes" threshold
    configurable.
-   Use existing completion records as the source of truth.
-   Add unit tests for all unlock edge cases.
-   Ensure old progress migrates safely and completed content stays
    accessible.

**Deliverable:** working Core → themes → Core progression, with no
lesson content regression.

## Phase 3 --- Build the French Core L1 content

placeholder cards: - subject pronouns; - articles and gender; -
être/avoir/aller/faire; - basic verbs; - possessives and determiners; -
basic prepositions and connectors; - question words; - negation; - basic
adjectives/adverbs; - sentence frames and examples.

Include enough content for a meaningful Core L1 course, but split it
into short skills/lessons. Each skill should have explicit outcomes and
a small set of new targets.

**Deliverable:** playable Core L1 with sentence-builder coverage.

## Phase 4 --- Build Theme L1 packs

Create a consistent L1 milestone for each theme in the visual map. Each
pack must include: - theme-specific target vocabulary; - a few useful
expressions/collocations; - simple dialogues; - sentence examples using
Core L1; - the existing activity types; - a cumulative review.

**Deliverable:** learner can choose at least three themes and build
basic sentences in each.

## Phase 5 --- Implement shared vocabulary mixing

Add a session vocabulary resolver that assembles: - current theme
targets; - current Core targets; - mastered Core review; - selected
mastered theme review; - bridge words.

Migrate activity types to use the resolver incrementally. Preserve
deterministic exercise generation where needed for tests and debugging.

**Deliverable:** theme exercises genuinely reuse Core vocabulary and
structures.

## Phase 6 --- Expand Core L2 and theme L2

Only after L1 works end-to-end: - add Core L2 grammar and vocabulary; -
add L2 milestone content to themes; - verify Core L2 unlocks after three
distinct L1 themes; - verify Theme L2 is only available after Core L2.

Continue to L3--L6 in the same pattern.

## Phase 7 --- QA, analytics and tuning

Track: - completion and drop-off per Core tier/theme tier; -
sentence-builder success rate; - most frequent grammar errors; -
vocabulary recall after 1, 7 and 30 days if spaced repetition exists; -
number of mastered Core items reused in theme sessions; - exercise
rejection/ambiguity rate; - learner retries and hint use.

Do not optimise solely for lesson completion speed. The goal is usable
sentence production and retention.

# 15. Short instruction to Kiro

Implement this specification as a **data-driven French curriculum**, not
as a hard-coded visual unlock demo.

First inspect the real Angular/Ionic project and its existing deck,
lesson/session engine, progress model and unlock logic. Then report the
current architecture and propose a safe mapping of existing French
skills/cards into the six Core tiers and thematic milestones.

Preserve existing IDs and user progress wherever possible. Build the
progression engine and tests before changing the UI. Core L1 should
teach the basic sentence engine; Theme L1 should let learners apply it
to real subjects; Core L2 should expand the sentence structures; and the
loop should continue. Theme activities must actually combine their topic
vocabulary with Core vocabulary and previously mastered language, using
a shared session vocabulary resolver.

Do not generate hundreds of unreviewed words or sentences in one pass.
Create a high-quality L1 vertical slice first, validate it end-to-end,
and then expand systematically. Every French noun must carry
gender/article metadata, every verb must have lemma/conjugation
metadata, and every sentence must be grammatically and idiomatically
validated.

Before implementation, identify any conflicts between this specification
and the current codebase. Do not silently remove features or invent the
structure of the existing deck.
