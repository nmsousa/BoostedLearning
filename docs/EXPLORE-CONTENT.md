# Explore content (French)

Every word and example sentence in Explore, as shipped in
`src/app/maps/tree/tree-curriculum.ts`. Regenerate with
`node scripts/export-explore-content.mjs`.

- **French** is shown as the app displays it today (nouns WITH their article,
  e.g. "le café").
- **English** gender notes are written as "(m.)" / "(f.)".
- **Icon** is the emoji shown on the Learn card (blank = none yet).

## Core

### Core level 1 — Name things

**Goal:** Name people and things, and join them with “and” / “or”.

**Example sentences:**

- Un professeur et un élève.
- C’est une école.
- J’ai un livre.

| French | English | Note | Icon |
|---|---|---|---|
| je | I | the subject “I”. Drops the e before a vowel sound: je + ai → j’ai. |  |
| un | a (m.) | indefinite article for a masculine noun: un livre. |  |
| une | a (f.) | indefinite article for a feminine noun: une pomme. |  |
| le | the (m.) | “the” before a masculine noun: le livre. |  |
| la | the (f.) | “the” before a feminine noun: la pomme. |  |
| l’ | the (before a vowel) | le/la both become l’ before a vowel or mute h: l’école, l’ami. |  |
| et | and | joins two things: un café et un thé. |  |
| ou | or | offers a choice: le café ou le thé ? (no accent — “où” with an accent means “where”). |  |
| oui | yes |  |  |
| non | no |  |  |
| c’est | it is / this is | point something out: c’est une école. Short for “ce est”. |  |
| j’ai | I have | “I have”, from avoir. je + ai → j’ai. |  |
| l’ami | friend (m.) | a male friend. The bare word is “ami”; with “the” it’s l’ami (a → l’). |  |
| l’amie | friend (f.) | a female friend. Sounds the same as l’ami; the -e is only written. |  |

### Core level 2 — Be & have

**Goal:** Say who is where and who has what.

**Example sentences:**

- Je suis ici.
- Tu as un livre, mais il a une question.

| French | English | Note | Icon |
|---|---|---|---|
| être | to be | the verb “to be”. Very irregular — learn its forms as set phrases: je suis, tu es, il/elle est… |  |
| avoir | to have | the verb “to have”. Also used to build the past tense later. Forms: j’ai, tu as, il/elle a… |  |
| je suis | I am | être with “I”: je suis ici. |  |
| tu es | you are | être with informal “you” (one person you know): tu es là. |  |
| il est | he is / it is | être with “he/it”. “il est” also tells the time later. |  |
| elle est | she is / it is | être with “she/it (f.)”. |  |
| tu as | you have | avoir with informal “you”: tu as un livre. |  |
| il a | he has | avoir with “he/it”. The -a is silent-ish; don’t confuse with “à” (to/at). |  |
| elle a | she has | avoir with “she/it (f.)”. |  |
| ici | here | a place near the speaker: je suis ici. |  |
| là | there | a place further away. Written with an accent to tell it apart from “la” (the). |  |
| mais | but | contrasts two ideas: tu as un livre, mais j’ai un stylo. |  |

### Core level 3 — Describe

**Goal:** Say whose it is and what it is like.

**Example sentences:**

- C’est mon livre.
- Une petite maison.
- Elle est très contente.

| French | English | Note | Icon |
|---|---|---|---|
| mon | my (m.) | agrees with the THING owned, not the owner. Also used before any feminine noun starting with a vowel: mon école, mon amie. |  |
| ma | my (f.) | before a feminine noun: ma mère. Becomes “mon” before a vowel sound (mon école). |  |
| ton | your (m.) | informal “your” (tu). Also before a feminine vowel noun: ton amie. |  |
| ta | your (f.) | informal “your” before a feminine noun: ta sœur. Becomes “ton” before a vowel. |  |
| grand | big / tall | adjective. Feminine: grande. Usually goes BEFORE the noun: un grand livre. |  |
| petit | small / little | feminine: petite. Goes before the noun: une petite maison. |  |
| bon | good | feminine: bonne. Goes before the noun: un bon café. |  |
| mauvais | bad | feminine: mauvaise (the masculine and plural look the same). |  |
| nouveau | new | feminine: nouvelle. Before a masculine vowel noun it becomes “nouvel”: un nouvel ami. |  |
| content | happy / glad | feminine: contente. Describes a person’s mood: elle est contente. |  |
| très | very | strengthens an adjective or adverb: très grand, très bien. |  |
| aussi | also / too | “too / as well”, usually at the end: j’ai un chien aussi. |  |

### Core level 4 — More people, more things

**Goal:** Use plurals and every person of être / avoir.

**Example sentences:**

- Nous avons des livres.
- Ils sont contents.

| French | English | Note | Icon |
|---|---|---|---|
| les | the (plural) | “the” for plural nouns of either gender: les livres, les écoles. |  |
| des | some (plural) | plural of un/une — “some”: des livres. English often drops it (“I have books”). |  |
| on | we / people (informal) | very common spoken “we”. Takes the SAME verb form as il/elle: on a, on est. |  |
| nous | we | the formal/written “we”: nous sommes, nous avons. |  |
| vous | you (plural / polite) | for several people, or one person politely. |  |
| ils | they (m. / mixed) | use for all-male OR a mixed group. |  |
| elles | they (f.) | use only when every person/thing is feminine. |  |
| nous sommes | we are | être with “we”. |  |
| vous êtes | you are (plural / polite) | être with vous. Liaison: sounds like “vou-z-êtes”. |  |
| ils sont | they are | être with ils/elles. Don’t confuse with “ils ont” (they have). |  |
| nous avons | we have | avoir with “we”. |  |
| vous avez | you have (plural / polite) | avoir with vous. |  |
| ils ont | they have | avoir with ils/elles. “ils ont” = have, “ils sont” = are — listen for the liaison “ils-z-ont”. |  |

### Core level 5 — Where things are

**Goal:** Place people and things.

**Example sentences:**

- Le livre est sur la table.
- Il y a un chat sous le lit.

| French | English | Note | Icon |
|---|---|---|---|
| dans | in / inside | inside something: dans la maison. |  |
| sur | on | on top of a surface: sur la table. |  |
| sous | under | underneath: sous le lit. |  |
| devant | in front of | devant la porte. |  |
| derrière | behind | derrière la maison. |  |
| à côté de | next to | the “de” contracts: à côté du restaurant, à côté de la gare. |  |
| avec | with | together with: avec un ami. |  |
| sans | without | the opposite of avec: un café sans sucre. |  |
| à | to / at / in | direction or location. Before “le/les” it MUST contract → au / aux. |  |
| au | to the / at the (m.) | à + le = au: je vais au restaurant. (Never say “à le”.) |  |
| à la | to the / at the (f.) | à does NOT contract with la or l’: à la gare, à l’école. |  |
| il y a | there is / there are | fixed phrase for “there is/are”, singular or plural: il y a un chat. |  |

### Core level 6 — Everyday verbs

**Goal:** Say what you like, want, can do and where you go.

**Example sentences:**

- J’aime le café.
- Je vais à la gare.
- Je veux apprendre.

| French | English | Note | Icon |
|---|---|---|---|
| aimer | to like / to love | the infinitive (dictionary form). With a general noun use “the”: j’aime le café = I like coffee. |  |
| aller | to go | irregular. Also builds the near future: je vais + verb = “I’m going to…”. |  |
| faire | to do / to make | very common; also used for weather and activities: je fais du sport. |  |
| vouloir | to want | to want. For a polite “I’d like”, use “je voudrais” (Core 11). |  |
| pouvoir | can / to be able to | followed by another verb in the infinitive: je peux parler. |  |
| parler | to speak / to talk | regular -er verb — a good model for conjugation: je parle, tu parles… |  |
| j’aime | I like / I love | aimer with “I”. je + aime → j’aime. |  |
| je vais | I go / I’m going | aller with “I”. je vais à la gare; je vais manger = I’m going to eat. |  |
| je fais | I do / I make | faire with “I”: je fais mes devoirs. |  |
| je veux | I want | direct. Softer: je voudrais (Core 11). |  |
| je peux | I can | add an infinitive: je peux venir. |  |
| je parle | I speak | je parle français; je parle un peu. |  |

### Core level 7 — Ask & say no

**Goal:** Ask simple questions, say “not” and give a reason.

**Example sentences:**

- Où est la gare ?
- Ce n’est pas un livre.

| French | English | Note | Icon |
|---|---|---|---|
| qui | who | asks about a person: qui est-ce ? |  |
| qu’est-ce que | what (in a question) | ready-made “what” at the start of a question: qu’est-ce que c’est ? |  |
| où | where | asks about a place: où est la gare ? (accented “où”, not “ou” = or). |  |
| quand | when | asks about time: quand est le cours ? |  |
| comment | how | also “what?” when you didn’t hear, and in comment ça va ? |  |
| pourquoi | why | answer it with “parce que…”. |  |
| combien | how much / how many | for an amount. With a noun: combien de livres ? (Core 10). |  |
| quel | which / what (m.) | goes with a masculine noun: quel livre ? |  |
| quelle | which / what (f.) | feminine form (sounds the same): quelle école ? |  |
| est-ce que | (yes/no question marker) | put it in front of a statement to make a yes/no question: est-ce que tu as un livre ? |  |
| ne… pas | not | wraps the verb: je ne suis pas ici. “ne” becomes n’ before a vowel: ce n’est pas… |  |
| parce que | because | gives a reason. Before il/elle it elides: parce qu’il… |  |

### Core level 8 — About me & when

**Goal:** Introduce yourself and say when things happen.

**Example sentences:**

- J’habite ici.
- J’ai un examen demain.

| French | English | Note | Icon |
|---|---|---|---|
| s’appeler | to be called | a reflexive verb (literally “to call oneself”). Used to give names. |  |
| je m’appelle | my name is | literally “I call myself”: je m’appelle André. |  |
| habiter | to live (somewhere) | regular -er verb. Use with à + place: j’habite à Paris. |  |
| j’habite | I live | the h is silent, so je → j’: j’habite ici. |  |
| maintenant | now | at this moment: je suis ici maintenant. |  |
| aujourd’hui | today | one word with an apostrophe inside; don’t add spaces. |  |
| demain | tomorrow | the day after today: j’ai un examen demain. |  |
| hier | yesterday | the day before today; used with the past tense. |  |
| bien | well | describes HOW (an adverb): je vais bien = I’m doing well. |  |
| beaucoup | a lot / very much | j’aime beaucoup le café. With a noun add “de”: beaucoup de livres (Core 10). |  |
| un peu | a little | a small amount: je parle un peu. |  |
| toujours | always / still | can mean “always” or “still”, depending on context. |  |

### Core level 9 — Daily actions

**Goal:** Take, eat, drink, buy, come and leave.

**Example sentences:**

- Je prends le train.
- Je mange une pomme.

| French | English | Note | Icon |
|---|---|---|---|
| prendre | to take | irregular. Also “to have” food/drink: je prends un café. |  |
| je prends | I take / I’ll have | je prends le train; je prends un café. |  |
| manger | to eat | regular -er verb: je mange, tu manges… |  |
| je mange | I eat | je mange une pomme. |  |
| boire | to drink | irregular: je bois, tu bois… |  |
| je bois | I drink | je bois de l’eau. |  |
| acheter | to buy | note the accent change: j’achète (è) in the “I” form. |  |
| j’achète | I buy | j’achète un billet. |  |
| venir | to come | irregular. “venir de” + verb means “to have just…” (Core 12). |  |
| je viens | I come | je viens avec un ami. |  |
| partir | to leave | to leave/depart (go away), vs sortir (go out). |  |
| je pars | I leave | je pars maintenant. |  |

### Core level 10 — How much & how often

**Goal:** Talk about quantities (some, a lot of) and frequency.

**Example sentences:**

- Je bois de l’eau.
- J’ai beaucoup de livres.

| French | English | Note | Icon |
|---|---|---|---|
| du | some (m.) | partitive = an unspecified amount. de + le = du: je bois du café. |  |
| de la | some (f.) | partitive before a feminine noun: de la viande. (de + la does NOT contract.) |  |
| de l’ | some (before a vowel) | partitive before a vowel: de l’eau. |  |
| beaucoup de | a lot of | quantity words take plain “de” (never du/des): beaucoup de livres. |  |
| un peu de | a little (of) | for uncountable things: un peu de sucre. |  |
| trop de | too much / too many | always “de”: trop de travail. |  |
| assez de | enough | assez de temps = enough time. |  |
| souvent | often | frequency adverb, usually after the verb: je prends souvent le train. |  |
| parfois | sometimes | occasionally. |  |
| d’habitude | usually | often starts the sentence: d’habitude, je mange ici. |  |
| rarement | rarely | not very often. |  |
| combien de | how much / how many (of) | combien + de + noun: combien de livres ? |  |

### Core level 11 — Needs & wishes

**Goal:** Ask politely, say what you need, must or prefer.

**Example sentences:**

- Je voudrais un café.
- J’ai besoin d’un billet.

| French | English | Note | Icon |
|---|---|---|---|
| je voudrais | I would like | the polite way to ask for something (softer than “je veux”): je voudrais un café. |  |
| j’ai besoin de | I need | literally “I have need of”. Followed by de + noun/verb: j’ai besoin d’un billet. |  |
| j’ai envie de | I feel like | to feel like / want: j’ai envie d’un café; j’ai envie de partir. |  |
| il faut | you have to / it’s necessary | impersonal “one must”. Add an infinitive: il faut partir. |  |
| devoir | must / to have to | obligation. Followed by an infinitive: je dois travailler. |  |
| je dois | I must / I have to | devoir with “I”: je dois partir. |  |
| préférer | to prefer | accents flip in the “I” form: je préfère. |  |
| je préfère | I prefer | je préfère le thé. |  |
| donc | so / therefore | states a result: je pense, donc je suis. |  |
| alors | then / so | links ideas in speech, like English “so…”. |  |
| si | if | introduces a condition. Becomes s’ before il/ils: s’il… |  |
| ça va | how’s it going? / fine | both a question and an answer: “Ça va ?” / “Ça va.” |  |

### Core level 12 — Past & plans

**Goal:** Say what you did, just did, or are going to do.

**Example sentences:**

- J’ai fini le livre.
- Elle est allée à la gare.

| French | English | Note | Icon |
|---|---|---|---|
| j’ai mangé | I ate / I have eaten | past tense (passé composé): avoir + past participle. Most verbs use avoir. |  |
| j’ai fini | I finished / I have finished | past of finir. -ir verbs end the participle in -i. |  |
| il est allé | he went | a few movement verbs use ÊTRE in the past, and the ending agrees with the subject. |  |
| elle est allée | she went | feminine subject → add -e to the participle: allé → allée (sounds the same). |  |
| je vais manger | I’m going to eat | near future: je vais + infinitive = “I’m going to…”. |  |
| je viens de finir | I’ve just finished | recent past: venir de + infinitive = “to have just…”. |  |
| d’abord | first | orders steps: d’abord…, ensuite…, enfin… |  |
| ensuite | then / next | the next step after d’abord. |  |
| enfin | finally | the last step in a sequence. |  |
| avant | before | earlier in time. “avant de” + infinitive = before doing. |  |
| après | after | later in time: après le dîner. |  |
| pendant | during | for a stretch of time: pendant le cours. |  |

### Core level 13 — Routines

**Goal:** Describe your day with reflexive and common action verbs.

**Example sentences:**

- Je me lève.
- Je dois fermer la porte.

| French | English | Note | Icon |
|---|---|---|---|
| se lever | to get up | reflexive: the action is on yourself. The “se” changes with the subject: je ME lève. |  |
| se réveiller | to wake up | reflexive. Wake up (réveiller) vs get out of bed (se lever). |  |
| se coucher | to go to bed | reflexive: je me couche. |  |
| s’habiller | to get dressed | reflexive; se → s’ before the vowel: je m’habille. |  |
| je me lève | I get up | se lever with “I”: the “se” becomes “me”. |  |
| commencer | to begin / to start | “commencer à” + infinitive = start doing. |  |
| terminer | to finish / to end | close in meaning to finir. |  |
| continuer | to continue | “continuer à” + infinitive = keep doing. |  |
| oublier | to forget | regular -er verb: j’oublie. |  |
| rencontrer | to meet | to meet someone (by chance or for the first time). |  |
| ouvrir | to open | irregular: its “I” form is j’ouvre (like an -er verb). |  |
| fermer | to close | the opposite of ouvrir: je ferme la porte. |  |

### Core level 14 — Linking ideas

**Goal:** Replace nouns with pronouns and link sentences.

**Example sentences:**

- Je le prends.
- C’est le livre que je veux.

| French | English | Note | Icon |
|---|---|---|---|
| le | him / it (object) | object pronoun, placed BEFORE the verb: je le prends. (Different from the article “le”.) |  |
| la | her / it (object) | object pronoun before the verb: je la vois. Becomes l’ before a vowel. |  |
| les | them (object) | plural object pronoun before the verb: je les prends. |  |
| lui | to him / to her | means “to him/her”. Used with verbs like parler: je lui parle. |  |
| qui | who / which (relative) | links clauses as the SUBJECT: le livre qui est sur la table. |  |
| que | that / which (relative) | links clauses as the OBJECT: le livre que je veux. Becomes qu’ before a vowel. |  |
| pourtant | yet / however | signals a contrast / something surprising. |  |
| récemment | recently | in the near past. |  |
| depuis | since / for | how long something has been going on: j’habite ici depuis 2020. |  |
| le souvenir | memory / souvenir | a masculine noun: un bon souvenir. |  |
| le projet | plan / project | masculine noun: un nouveau projet. |  |
| l’expérience | experience (f.) | feminine noun (the article hides the gender): une bonne expérience. |  |
